# SmilesMerger

> [!WARNING]
> **Deprecated:** This API is no longer used. Fragment merging for Interactive Spectroscopy Explorer is now handled locally.

API responsible for merging molecular fragments strings for the interactive canvas in [Interactive Spectroscopy Explorer](https://github.com/biochem-learning/spectrum-app-v2).

### Installation

```bash
git clone <repository-url>
cd SmilesMerger

python -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

On Windows:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```
